# HTML Resumes

A collection of professionally designed, print-ready HTML resumes.

## Features

- Single A4 page layout
- Print-ready (Ctrl+P > Save as PDF)
- Inter font (Google Fonts)
- Responsive design
- Clean, minimal design

## Usage

1. Open the HTML file in a browser
2. Press `Ctrl+P` and select "Save as PDF"
3. Set paper size to A4, margins to None
4. Enable "Background graphics"
